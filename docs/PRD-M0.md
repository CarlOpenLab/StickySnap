# StickySnap PRD — M0（贴图成立的最小集）

> 依据竞品调研定稿（见仓库外《截图工具竞品分析与功能清单》）：贴图 pin 是三大系统都无原生等价物的独占功能，为第一刚需。M0 范围冻结，功能 ×3（三端）是最大风险。

## 1. 核心循环

```
F1 截图（窗口元素吸附 → 框选）→ Enter/双击 贴上桌面
F3 剪贴板（图片）→ 直接贴上桌面
贴图长存桌面，重启自动恢复
```

## 2. M0 验收标准

### 2.1 触发
- [x] 全局热键 F1（截图）、F3（贴剪贴板），托盘菜单等效入口
- [x] 单实例：重复启动直接退出

### 2.2 截图
- [x] F1 后冻结全虚拟屏（多显示器拼接，含 CAPTUREBLT 分层窗），叠加 45% 暗色遮罩
- [x] 拖拽矩形选区；选区外保持暗色、选区内显示原图；边框 2px 红色 + 实时尺寸标签
- [x] 未拖拽时：光标下窗口自动高亮（2px 青色），跳过桌面/贴图/自身/隐身窗口
- [x] 单击 = 直接选中高亮窗口（贴图式快捷选窗）
- [x] 放大镜：光标右下 9×9 物理 px ×12 放大 + 白色边框 + 中心十字 + #RRGGBB 色值
- [x] Enter / 双击 → 贴图；Ctrl+C → 复制到剪贴板；Esc → 取消
- [x] 选区 < 3px 视为无效

### 2.3 贴图
- [x] 置顶、无边框、不进任务栏/Alt-Tab（TOOLWINDOW）、不抢焦点（NOACTIVATE）
- [x] 拖动移动；滚轮缩放（0.1–8.0，缩放质量 ≥1 用 HALFTONE）；Ctrl+滚轮透明度（32–255）
- [x] 双击关闭；右键菜单：鼠标穿透（可勾选）/ 复制 / 另存为 PNG|JPG / 关闭
- [x] 鼠标穿透 = WS_EX_TRANSPARENT 开关
- [x] **贴图不出现在后续 F1 截图里**（SetWindowDisplayAffinity WDA_EXCLUDEFROMCAPTURE）
- [x] 截图期间：贴图升至遮罩之上保持可见，但临时鼠标穿透（不拦截选区），结束后恢复
- [x] F3：剪贴板 PNG 优先、CF_DIB 兜底；无图片时静默忽略（M1 改为提示）

### 2.2b 标注工具栏（M0.5，用户验收后新增）

- [x] 选区完成后在选区右下角弹出图标工具栏（放不下则上方，自动钳制屏幕内）
- [x] 工具行：矩形 / 椭圆 / 箭头 / 画笔 / 荧光笔 / 马赛克 | 撤销 | 贴图 / 复制 / 保存 / 取消
- [x] 颜色行：9 色色板 + 3 档粗细；激活工具高亮（蓝底）；再次点击工具取消激活
- [x] 工具激活后：在选区内拖拽绘制；画笔/荧光笔/马赛克为折线笔迹，其余拉框
- [x] 荧光笔半透明（alpha 110/255）；马赛克按 10px 块取平均像素化，沿笔刷圆点区域生效
- [x] 撤销：按钮或 Ctrl+Z；切换工具/重选区域时放弃进行中笔画
- [x] 贴图 / 复制 / 保存 / 双击 输出合成标注后的图像（马赛克 + 荧光笔 + 形状按序合成）
- [x] 已有选区时选区内部点击不再重选（防误触丢标注）；选区外点击 = 重新框选

### 2.4 会话持久化（刚需：贴图 = 用户工作台，不能丢）
- [x] 贴图创建时图片即落盘 `%APPDATA%\StickySnap\pins\*.png`
- [x] `index.txt` 记录 图片路径/x/y/zoom/alpha/pass，tmp 文件 + MoveFileEx 原子替换
- [x] 变更后 800ms 延迟保存（拖动/缩放/透明度/增删均触发）
- [x] 启动自动恢复；位置钳制在当前虚拟屏内；图片文件丢失的条目跳过；上限 200 张

### 2.5 平台工程
- [x] Per-Monitor-V2 DPI aware，全程物理像素；放大镜/遮罩/选区跨屏坐标正确
- [x] 托盘 explorer 重启自恢复（TaskbarCreated）
- [x] CMake + GitHub Actions 构建（windows-latest，MSVC）

## 3. M0 明确不做

长截图、录屏/GIF、OCR、图床上传、贴图标注、GIF/文本/颜色贴图、热键自定义、UI 元素级（子控件）吸附、设置界面。

## 4. M1 预告（按用户价值排序）

1. 贴图上直接标注（进入编辑态）
2. GIF/WebP/APNG 动图贴图（滚轮=调速）
3. 文本 / HTML / 颜色 剪贴板贴图
4. 热键自定义 + 设置界面
5. UI 元素级吸附（MSAA / UI Automation 走查）
6. OCR（Windows.Media.Ocr 本地引擎）+ 表格提取

## 5. 已知限制（如实记录）

- GDI BitBlt 采集：不含硬件光标；性能足够 M0（Snipaste 1.x 同路径）
- 窗口检测为窗口级；UWP 隐身（cloaked）窗口已跳过，但元素级检测需 UIA（M1）
- CF_DIB 采用 top-down 负高度写法（主流软件均接受；极老软件可能不认，M1 可加 bottom-up 转换）
- 全局热键被占用时该热键失效（日志可见），M1 提供自定义
